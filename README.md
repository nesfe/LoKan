# LoKan

**Local kanban board** — лёгкое настольное приложение для личных задач на Electron. Работает без аккаунта, облака и сервера. Интерфейс на русском языке.

## Возможности

- Несколько независимых досок и настраиваемые статусы.
- Последовательные номера задач внутри каждой доски (`#001`, `#002` и далее). Номера не переиспользуются после удаления.
- Перетаскивание карточек между статусами и внутри колонок.
- Приоритеты, сроки, цветные карточки и теги, описания и чек-листы.
- Поиск по номеру, названию, описанию и тегам; фильтры по приоритету, тегу и сроку.
- Лимиты задач в колонках, архив с восстановлением, светлая и тёмная темы.
- Автоматическое локальное сохранение, резервное копирование, экспорт и импорт JSON.
- Горячие клавиши: `N` — новая задача, `Ctrl/Cmd+K` — поиск, `Esc` — закрыть окно.

## Запуск

Требуются Node.js 20+ и npm.

```bash
npm ci
npm start
```

Для проверки модели данных: `npm test`.

Для сборки установщика на своей системе: `npm run dist:linux`, `npm run dist:win` или `npm run dist:mac`. Готовые файлы появятся в `dist/`. Windows-установщик автоматически собирается на Windows runner в GitHub Actions. Подпись для Windows/macOS в проекте не настроена.

## Хранение данных

Файл `lokan.json` лежит в каталоге данных приложения Electron (`userData`), а предыдущая версия файла — в `lokan.backup.json`. Точный путь показан в настройках. Запись выполняется через временный файл и переименование. Отдельная база данных не нужна: весь набор досок хранится в одном локальном файле, который можно экспортировать.

Импорт **заменяет** текущие доски. Перед импортом удобно сделать экспорт. Данные не отправляются по сети.

## Технологии

Electron и нативные HTML, CSS, JavaScript без фронтенд-фреймворка. Интерфейс изолирован от Node.js через `contextIsolation` и ограниченный preload API. Содержимое задач отображается как текст.
